# GSE67005 frozen public excerpt

This fixture contains the header and first 10 data rows of
`GSE67005_T5_LD_ratios.txt.gz`, retrieved from NCBI GEO on 2026-07-27.
Values are copied without transformation.
`design.tsv` and `design.json` are curated representations of the deposited
sample titles and source descriptions for the same six columns.

- Series: <https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE67005>
- Frozen source: <https://ftp.ncbi.nlm.nih.gov/geo/series/GSE67nnn/GSE67005/suppl/GSE67005_T5_LD_ratios.txt.gz>
- Platform: GPL16284
- Publication: PMID 27153756

The source record describes primary human hepatocytes exposed for five days to
vehicle, 0.3 µM, or 1 µM aflatoxin B1, with three biological replicates per
condition. This excerpt uses the vehicle and 0.3 µM columns only.

The probe position is retained as deposited. No coordinate-system conversion
or genome-build assertion is made in this fixture, so it must not be used to
validate genomic interval semantics. The measured values are centered log2
MeDIP/Input ratios, not beta values.
